📘 Mémo SQL

  
Chaque clause, à quoi elle sert et comment l'écrire. Clique pour déplier.


  

    FROMWHEREGROUP BYHAVINGSELECTORDER BYLIMIT
  


  

    Ordre d'exécution logique
    

      
Le moteur SQL ne lit pas la requête dans l'ordre où tu l'écris (SELECT en premier) mais dans cet ordre : FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.

      
C'est pourquoi WHERE ne peut pas utiliser un alias défini dans le SELECT, et pourquoi HAVING peut filtrer sur un agrégat alors que WHERE ne le peut pas.

    

  


  

    SELECT
    

      
Choisit les colonnes (ou expressions) à afficher dans le résultat. * = toutes les colonnes.

      
SELECT nom, prix
FROM produits

    

  


  

    FROM
    

      
Indique la table (ou les tables, avec JOIN) sur laquelle porte la requête. Toujours la première clause exécutée.

      
SELECT * FROM clients

    

  


  

    WHERE
    

      
Filtre les lignes individuelles avant tout regroupement. Ne peut pas contenir de fonction d'agrégat (SUM, COUNT...).

      
SELECT * FROM produits
WHERE prix > 20000 AND stock < 50

      
Opérateurs utiles : = <> > < AND OR NOT

    

  


  

    LIKE / IN / BETWEEN
    

      
LIKE filtre du texte avec des jokers : % (0 ou plusieurs caractères), _ (1 caractère).

      
WHERE nom LIKE 'K%'      -- commence par K
WHERE ville IN ('Abidjan','Bouake')
WHERE prix BETWEEN 10000 AND 50000

    

  


  

    GROUP BY
    

      
Regroupe les lignes ayant la même valeur pour calculer un agrégat par groupe. Toute colonne non agrégée du SELECT doit apparaître dans le GROUP BY.

      
SELECT categorie, COUNT(*) AS nb
FROM produits
GROUP BY categorie

    

  


  

    Fonctions d'agrégation
    

      
COUNT() compte, SUM() additionne, AVG() fait la moyenne, MIN()/MAX() donnent le minimum/maximum. S'utilisent seules ou avec GROUP BY.

      
SELECT AVG(prix) AS prix_moyen
FROM produits

    

  


  

    HAVING
    

      
Filtre après le GROUP BY, sur le résultat des agrégats. C'est le "WHERE des groupes".

      
SELECT client_id, COUNT(*) AS nb
FROM commandes
GROUP BY client_id
HAVING COUNT(*) > 1

    

  


  

    ORDER BY
    

      
Trie le résultat final. ASC = croissant (défaut), DESC = décroissant. Peut trier sur plusieurs colonnes.

      
SELECT * FROM produits
ORDER BY prix DESC, nom ASC

    

  


  

    LIMIT
    

      
Restreint le nombre de lignes retournées. S'exécute en tout dernier, souvent combiné à ORDER BY pour le "top N".

      
SELECT * FROM produits
ORDER BY prix DESC
LIMIT 3

    

  


  

    DISTINCT
    

      
Supprime les doublons du résultat.

      
SELECT DISTINCT ville FROM clients

    

  


  

    JOIN (INNER / LEFT)
    

      
JOIN ... ON (= INNER JOIN) combine deux tables en ne gardant que les lignes qui correspondent des deux côtés. LEFT JOIN garde en plus toutes les lignes de la table de gauche, même sans correspondance (valeurs à NULL).

      
SELECT c.nom, COUNT(cm.id) AS nb
FROM clients c
LEFT JOIN commandes cm ON c.id = cm.client_id
GROUP BY c.nom

    

  


  

    Alias (AS)
    

      
Renomme une colonne, une expression ou une table pour rendre la requête plus lisible ou pour l'auto-jointure.

      
SELECT prix AS tarif
FROM produits p1

    

  


  

    CASE WHEN
    

      
Crée une colonne conditionnelle, un peu comme un si/sinon. Peut porter sur une valeur simple ou sur un agrégat.

      
SELECT nom,
  CASE WHEN stock < 20 THEN 'Stock faible'
       ELSE 'Stock ok' END AS etat
FROM produits

    

  


  

    Sous-requêtes (subqueries)
    

      
Une requête imbriquée dans une autre : dans WHERE (filtre dynamique), dans FROM (table temporaire) ou dans SELECT (valeur calculée).

      
-- dans WHERE
SELECT * FROM produits
WHERE prix > (SELECT AVG(prix) FROM produits)

-- corrélée : dépend de la ligne externe
SELECT nom FROM employes e1
WHERE salaire > (
  SELECT AVG(salaire) FROM employes e2
  WHERE e2.departement_id = e1.departement_id)

    

  


  

    CTE (WITH ... AS)
    

      
Une "Common Table Expression" nomme un résultat temporaire au-dessus de la requête principale, pour la rendre plus lisible qu'une sous-requête imbriquée. Réutilisable plusieurs fois dans la même requête.

      
WITH ventes_client AS (
  SELECT client_id, SUM(quantite*prix) AS total
  FROM lignes_commande lc
  JOIN produits p ON lc.produit_id = p.id
  GROUP BY client_id
)
SELECT * FROM ventes_client
WHERE total > 50000

    

  








Astuce : la casse et l'ordre des colonnes n'ont pas d'importance, seul le résultat compte.
